# SingnarPay

A student payment platform built with Next.js and Solana.

## Features

- Solana wallet connection
- SOL balance and INR estimate
- SOL transfers and memo transactions
- SPL token minting and transfers
- Portfolio price chart
- Student marketplace and checkout
- Finance and rewards pages

## Tech Stack

- Next.js
- TypeScript
- Solana
- Prisma
- SQLite
- Recharts

## Getting Started

1. Install Node.js.
2. Clone or download this repository.
3. Install dependencies:

   npm install

4. Configure your environment variables using `.env.example`.
5. Run database migrations as documented for this project.
6. Start the development server:

   npm run dev

7. Open http://localhost:3000

## Network

Solana Devnet — test transactions only.

## Limitations

Marketplace checkout is a test checkout and does not collect real payment.
Devnet SOL has no real monetary value.
Portfolio INR values are estimates.
